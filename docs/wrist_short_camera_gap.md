# 同一世界坐标系的短相机缺口：腕部联合优化

正式导出默认启用，位于 `tools/export_action_labels.py::_optimize_wrists_by_submap`。

相机一帧失效会使该帧的 world/map ID 为空，但不意味着前后有效观测属于不同地图。
原来的外层连续分段会把短缺口两侧独立求解，使单面腕码的深度/倾角弱约束在两侧形成不同偏差。

现在仅在以下条件下共享腕部优化窗口：前后是同一最终 world/map ID，中间没有另一个地图，
且两侧相机帧的实际时间差不超过 0.15 秒。内部仍采用原有 0.15 秒腕部有效观测间隔限制。
非米制/未分配地图/无相机位姿的帧不参与投影因子，不产生腕部世界位姿。
原始图像、相机位姿、地图、角点、腕带标定均不改变；不引入零速度约束，也不插值测量。

这是离线估计器的分段修正，不是显示连线或平滑参数调整。短缺口后的真实运动仍由原始角点约束。
两个原先被隔离的单码观测可以因邻近有效几何支持而获得估计，但没有角点/相机测量的帧仍无效。

验证：`tests/test_wrist_short_camera_gap.py` 覆盖短缺口、地图隔离、长缺口、未配对端点，
以及已知 0.6 m/s 平移、0.8 rad/s 旋转与移动相机的合成投影测试。
实拍 A/B 与完整回放报告位于 `output/samsung_static4_rev5_20260914/wrist_gap_fix/`。
实拍静止散布仅是精密度指标；动态片段的删帧对照以未删帧输出为参考，不作为外部真值。
