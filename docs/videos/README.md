# Demo provenance

All clips are excerpts of existing English offline-reconstruction demonstrations.
No SLAM, inference or map generation was rerun. Privacy masking is preserved.
Silent H.264 MP4, 1920 × 1080, 24 FPS. Playback rates are not processing rates.

| File | Edited source-video interval | Meaning |
|---|---|---|
| retrospective.mp4 | 12–24 s | Forward vs offline image-to-map matches; includes a deliberate pause |
| reanchoring.mp4 | 91–99 s | Source recording 118–126 s; accepted scale update at 121.73 s |
| merge-loop.mp4 | 113–131 s | Source recording 184–193 s at 0.5×; merge 187.73 s, loop update publication 188.40 s |

The retrospective comparison comes from a different recording than the map-event
examples. The left Atlas is the final offline map; the right map pane replays
recorded construction and committed events. Highlight timing refers to the event
publication shown in the existing replay, not wall-clock optimizer runtime.

These previews demonstrate behavior, not an accuracy benchmark.

README animations are 7-second looping GIF excerpts, 800 × 450 at 10 FPS.
They retain the MP4 playback timing (no additional speed-up): retrospective
uses clip seconds 1–8, re-anchoring 1–8, and merge/loop 5–12. Click the
animation for the complete 1080p MP4. GIF playback can depend on viewer
accessibility and reduced-motion preferences.
